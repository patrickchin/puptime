Puptime tracks one puppy. Free local logging, editing, history, routines, and reminders work offline without an account. First-open setup lets you name your puppy and continue locally. The feature walkthrough can be skipped or replayed from Settings.

Cloud accounts are optional. Use Backup and sync in Settings to sign in with the methods offered by the release, then explicitly enable cloud access. Signing in alone does not upload puppy records. Local data stays available when the network is unavailable or cloud access expires. Test the cloud path only against the release environment and review account supplied with the submitted build.

Account management is available at https://puptime.pages.dev/account. After signing in, you can download cloud data, manage connected sign-in methods, sign out, or request cloud-account deletion. Deletion requires fresh verification and a separate confirmation. Cloud-account deletion leaves device-local records and previously downloaded files intact.

For reminders, enable a reminder and allow notifications when prompted. Dictation requests Microphone and Speech Recognition only when used.

In Insights, Export CSV opens the system share sheet and Import CSV opens the file picker. Importing the same file skips existing entries and keeps current edits. Deleting one exported entry and importing the file again restores the missing entry. Activity CSV files do not include routines or settings.

Estimated entries remain labelled in Log, Timeline, Insights, and activity CSV files. Faded suggestions in Timeline are not saved or exported until added.
