# Puppy guide narration

These English recordings adapt Puptime’s original care summaries for listening, with conversational transitions and a closing source note. They preserve the guidance and its caveats rather than reading each heading and paragraph verbatim. Linked articles and videos remain in the written guides. They were generated on 15 October 2026 using ElevenLabs v4 and “Joanna - Warm & upbeat” (voice ID `dVoi15NNDJligFBwnVO0`). The owner approved a short sample before the full set was generated.

`src/guide-scripts.ts` contains the spoken adaptations. `manifest.json` records the actual spoken script, a snapshot of the written source, voice, model, generation reference, duration, and settings. `src/guide-recordings.ts` controls the shared native/web shipping registry, which currently excludes this noncommercial set. When licensed recordings are registered, playback uses bundled assets without ElevenLabs requests or generation credits. No API credentials belong in the app, exported website, manifest, or repository.

When care guidance changes, review the spoken adaptation against the written article. Generate its audio from `guideNarration` in `src/guide-scripts.ts`, review the result, replace the MP3, and update its manifest entry. Preserve the current written-source snapshot from `guideSourceText` in `src/guide-audio.ts`. The player hides recordings when the written source changes; tests also require every recording to match its spoken script before release. Native playback continues with the screen locked and stops when leaving the guide.

For registered recordings, playback lives in a full-width bar below the independently scrolling article on both the website and native app. It has a seek slider, skip buttons, speed selection, and mute; desktop web also has a volume slider. The app bar stays above the navigation tabs, with system volume controls available. Its seek track supports tapping, dragging, and accessibility increment/decrement actions. The native speed button opens a picker instead of showing four separate buttons.

When recordings are available on the website, each selected clip loads into a temporary browser blob before playback. Cloudflare Pages returns full responses to byte-range requests; using the complete clip keeps skipping and scrubbing reliable. Requests are cancelled and blob URLs released when leaving the guide.
