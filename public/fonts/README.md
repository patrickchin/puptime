# Website fonts

Red Hat Display (700 and 900) and Red Hat Text (400–500), Latin WOFF2 files, are self-hosted for the public marketing site. Both are licensed under the SIL Open Font License 1.1; the unmodified licenses accompany the files. `RedHatDisplay-OFL.txt` covers both Red Hat Display weights.

Sources: [Red Hat Display](https://github.com/google/fonts/tree/main/ofl/redhatdisplay), [Red Hat Text](https://github.com/google/fonts/tree/main/ofl/redhattext). Files were downloaded from Google Fonts on October 20, 2026; `RedHatDisplay-Bold-Latin.woff2` is the same Google Fonts Latin subset at weight 700, downloaded on November 27, 2026. No third-party font request is made at runtime.
