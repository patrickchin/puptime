# Website fonts

Red Hat Display (900) and Red Hat Text (400–500), Latin WOFF2 files, are self-hosted for the public marketing site. Both are licensed under the SIL Open Font License 1.1; the unmodified licenses accompany the files.

Sources: [Red Hat Display](https://github.com/google/fonts/tree/main/ofl/redhatdisplay), [Red Hat Text](https://github.com/google/fonts/tree/main/ofl/redhattext). Files were downloaded from Google Fonts on October 20, 2026. No third-party font request is made at runtime.
